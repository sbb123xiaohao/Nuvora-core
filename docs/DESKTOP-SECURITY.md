# 图形桌面与安全边界（0.15.0）

UEFI/GOP 正常启动显示品牌启动画面、图形 OOBE/登录及桌面。内核留在
supervisor 地址空间，应用运行在 Ring 3；窗口终端是用户态 Loom，通过
受检查的系统调用请求文件、进程和设备操作，并不直接执行内核代码。
隐藏启动文字是界面行为；真正的访问限制由内核权限与页表执行。

## 日常桌面

桌面提供三种渐变壁纸、圆角窗口、阴影、抗锯齿字体、浮动 Dock、应用搜索、
窗口总览、MRU 切换和贴边平铺。Files、Text Editor、Terminal、Media、Folio
继续作为原生界面/进程工作；界面采用 GOP 软件绘制，壁纸缓存减少重复计算。
标题栏显示工作区与实际运行时长，不假装提供尚未实现的日历时钟。

Files 使用 Spaces 卡片和深青导航栏，支持即时搜索、文件夹优先排序、紧凑
列表及宽窗口的选中项详情。Ctrl-F 搜索，Ctrl-1/2 切换视图，F8 切换排序；
默认隐藏点文件，Ctrl-H 切换显示。隐藏和搜索都不改变内核的路径权限。

Start → Settings 有 Appearance、Sound、Network、Security、System 五页。
Sound 调整实际全局输出音量、静音/恢复；无 HDA 输出时按钮禁用。Network
自动更新网卡状态、IPv4、掩码、网关和 DNS，管理员可请求 DHCP 地址。
System 显示实时可用内存、任务数及运行时长。壁纸、1/5/15 分钟锁屏、
文件视图/排序/点文件显示和音量保存到当前用户的 `.desktop`；原 16 字节
壁纸/锁屏记录继续可读，新记录验证全部选项位，使用临时文件原子替换。
System 可保存数据；管理员可请求重启/关机，先确认，再处理未保存文档并
保存数据。确认默认选中 Cancel，保存失败会留在桌面显示错误。

## 会话与权限

PID 1 `/apps/session` 只监督桌面进程，不解释命令。正常菜单不提供返回
裸控制台的入口；桌面退出/崩溃后监督程序重新启动它，管理权丢失时内核
锁定身份、清除待处理秘密并结束其他应用。BIOS 文本模式或明确设置
`nv.recovery=1` 可使用恢复控制台，仍需同一账户服务的本地登录。

锁屏默认 5 分钟，由内核定时器执行。只有通过设备校验的实际键盘/指针
变化重置空闲时间；静止 USB Tablet 报告、后台绘制、网络和进程活动不算
操作。锁定期间窗口与后台计算可以继续，但普通应用不能接收/伪造控制台
输入或接管显示，启动器不能启动新应用。解锁恢复同一身份。

会话管理权绑定不可变的程序来源与父进程，而非可修改的进程名字或单独
PID 1。生产监督/管理进程不能 exec 任意 ELF 后继承信任。普通应用不能
领取管理权、改账户角色、退出/锁定全局会话或变更空闲策略。电源与网络
配置需要当前已解锁的管理员；普通用户仍可读取公开设备状态和执行允许
的网络收发。管理员程序同样不能读取受内核保护的账户数据库。

原有密码机制保留：随机盐、600,000 轮 PBKDF2-HMAC-SHA-256、失败等待、
秘密清零与规范路径权限。详细存储和共享目录规则见 [ACCOUNTS](ACCOUNTS.md)。

## 内核与发布介质

保留 supervisor 页隔离、NX 和 CR0.WP；CPUID 支持 SMEP 时设置 CR4.SMEP，
禁止内核执行用户页。较旧 x64 CPU 没有 SMEP 时继续使用现有页保护。
未启用 SMAP、IOMMU、多核隔离或每个应用独立的权限沙箱。

`make all`、`make esp`、`make media`、`make iso-uefi` 使用生产内核，忽略
`nv.test=1`。自测必须显式 `make diagnostics`，使用单独的 `boot-test.elf`
或 `nuvora-uefi-test.elf`；自动化测试只向临时镜像写入诊断内核。发布包
不携带该认证绕过路径。串口保留内核诊断，严重 panic 可以显示错误屏。

数据盘没有加密，启动镜像没有 Secure Boot 签名/验证链。可离线读取磁盘
或替换固件/内核的人仍有相应能力；本版不声称生产级安全认证。实体 PC
驱动和上机边界见 [NATIVE64-HARDWARE](NATIVE64-HARDWARE.md)。

本版实际模拟启动、权限、自动锁屏、窗口交互和电源测试，以及明确未验证
的范围，见 [TESTING](TESTING.md)。
