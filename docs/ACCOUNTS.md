# 本地账户

首次正常启动进入 OOBE：继续、建立第一个管理员、打开桌面。
已有账户时直接显示登录页。BIOS 文本模式有同一内核服务支持的用户名与
掩码密码输入。图形桌面异常退出由监督程序重新启动；失去会话管理进程会
锁定会话并结束其他应用，重新登录/解锁后才可继续。

## 使用

- 用户名：1–31 个字符，小写字母开头，其余允许小写字母、数字、`-`、`_`。
- 显示名：1–63 个可打印 ASCII 字符，可与用户名不同。
- 新密码：15–128 个可打印 ASCII 字符，允许空格；拒绝纯重复字符和少量
  常见弱密码。没有大写、数字或符号的强制组合要求。
- Start → Accounts：管理员添加用户、改显示名/身份、禁用、删除或重设密码；
  普通用户修改自己的显示名和密码。改密码/重设密码均要求当前登录人的密码。
- Win-L 或 Start 的 Lock：锁定当前会话，窗口继续运行，解锁前不接收键盘；未认证进程不能接管显示。
- 自动锁屏：默认 5 分钟，Settings → Security 可选 1/5/15 分钟，由内核根据真实键鼠活动计时，应用绘制和静止指针报告不能延长会话。
- Start 的 Sign out：先询问未保存文本和原生文档，随后结束会话进程并清除
  桌面缓存，再回到登录页。可在未保存提示中取消。
- Accounts 中用 Tab/Shift-Tab、方向键和 Enter；Alt-V 显示/隐藏密码，
  Alt-R 改身份、Alt-D 改启用状态。开始菜单中 Ctrl-L 锁屏、Ctrl-Q 退出登录。

删除账户需要明确选择 Remove account；默认焦点在 Cancel，Enter 不会默认
删除。当前账户和最后一个启用的管理员受保护。删除保留其目录，旧用户名
不能重用以继承这些文件。最多 32 个账户。

## 保存与访问

默认数据镜像能保存账户。没有可写数据盘时，OOBE 明确提示账户只存在于
本次启动；重启后重新设置。旧镜像会新增账户目录，不擦除已有文件。

每个用户有 `/home/users/用户名`。新文本和 Folio 文档默认保存到这个目录。
普通用户不能访问其他用户的私有目录；管理员可以访问。旧 `/home` 的文件、
其他数据卷和 `/tmp` 是共享区域，尚无逐文件 owner/group/mode 或配额。

内核保管 `/home/.system/accounts.db`，用户进程（含管理员应用）不能打开、
列出、移动或覆盖该目录。访问检查解析规范路径，覆盖 `C:/`、相对路径与
`..` 别名；打开描述符的读、写、seek、stat 会再次检查身份。

数据库先写临时文件、替换，再提交数据卷，提交确认后才报告成功。载入
错误/损坏不会重新显示可覆盖数据库的 OOBE；不确定的提交失败要求重启
重新载入。文件系统仍采用其原有双元数据根回退策略。

## 密码与边界

原创实现的 SHA-256、HMAC-SHA-256、PBKDF2 使用独立测试向量核对。
每个密码用 16 字节随机盐、600,000 轮 PBKDF2-HMAC-SHA-256，保存 32 字节
派生结果；不保存明文密码。盐来自处理器 RDSEED/RDRAND，无可用安全随机
源时拒绝创建/改密；启动器默认 QEMU `max`，旧 CPU 模型可用于兼容测试，
但不一定能建立账户。派生分批执行，界面进度来自内核实际轮数；请求秘密
在完成、取消和进程退出时清零，比较派生结果使用全长累积比较。

未知、禁用或密码错误均不登录。登录、解锁和改密码的旧密码验证共用失败
计数：连续五次失败后施加递增等待，最多 60 秒；等待期间不启动新的密码
验证，正确验证后清除失败计数。等待按经过的时间计算，覆盖计时器回绕；
重启会重置计数。锁屏只能解锁同一身份，切换用户需先退出会话。

这是本地登录与私有目录访问控制，数据盘没有加密；有宿主镜像或物理磁盘
访问的人仍可离线读取文件及密码散列。尚无完整弱密码库、联网身份、恢复
密钥、群组 ACL、安全启动信任链、审计日志或生产级安全认证。

参考：[OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、
[RFC 4231 HMAC vectors](https://www.rfc-editor.org/rfc/rfc4231)、
[NIST SP 800-63B-4](https://pages.nist.gov/800-63-4/sp800-63b.html)。

## 接口

`NV_SUB_ACCOUNT=8`，`NV_ACCOUNT_API_VERSION=1`；结构定义在 `include/nv/abi.h`，
用户包装为 `account_call(op, pointer)`。

| 操作 | 请求/输出与行为 |
| --- | --- |
| INFO / LIST | `nv_account_info` / `nv_account_profile`，只含公开资料 |
| CLAIM | 不可变程序来源为 PID 1 `/apps/loom` 恢复入口，或 PID 1 直接启动的 `/apps/desktop`；仅 PID 1 身份不足以领取 |
| SETUP / LOGIN / ADD / PASSWORD | `nv_account_request`，接受后返回 0，开始异步验证/保存 |
| POLL | `nv_account_progress`；0 为进行中、1 为结束，`result` 为最终错误码 |
| CANCEL | 清除未完成派生和请求秘密 |
| UPDATE / REMOVE | `nv_account_request`，同步修改资料/删除 |
| LOCK / LOGOUT | 锁定或结束当前会话；退出结束应用并撤销会话身份 |
| POLICY_GET / POLICY_SET | `nv_account_policy`；仅管理入口可用，SET 要求已解锁，超时限于 1–15 分钟 |

管理权只对可信入口开放；应用进程只能查询公开资料。锁屏也阻止后台进程
接管显示/窗口服务器、读取或伪造普通控制台输入输出。身份在 spawn 继承，
exec 保持，退出释放持有的管理权和秘密作业。生产监督与管理进程禁止 exec
任意 ELF，防止保留可信进程身份后替换程序。关机、重启和网络配置检查真实
的已解锁管理员身份，不因 PID 1 或管理进程身份直接放行。

生产内核忽略 `nv.test=1`。只有 `make diagnostics` 单独生成的诊断内核可
关闭认证运行自测，发布介质不包含它。拥有固件/引导配置或磁盘控制权的人
仍可替换整个未签名内核；安全启动与离线磁盘加密尚未实现。
